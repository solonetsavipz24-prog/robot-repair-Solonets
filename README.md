# Robot Repair — Unity

## Лабораторна робота

**Виконав:** Солонець Артем  
**Мова:** C# / Unity  
**Версія Unity:** 6.3  
**Тип проєкту:** 2D URP

## Мета роботи

Запустити готову гру **Adventure Game: Robot Repair** та змінити її зовнішній вигляд шляхом перемикання наборів артів.

## Виконана робота

- Створено 2D URP-проєкт у Unity 6.3.
- Імпортовано набір **Adventure Game: Robot Repair** з Unity Asset Store.
- Відкрито та запущено готову сцену гри.
- Перемкнуто набір артів.
- Повторно запущено гру для демонстрації зміненого вигляду.
- Створено GitHub-репозиторій та виконано перший коміт.
